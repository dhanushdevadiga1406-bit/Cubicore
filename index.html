SECURITY & CONCURRENCY

How Associates Are Kept Apart

OpenCode 1.18.x cannot restrict an agent to a path; its permissions are per-action, not per-resource. Cubicore provides three layers of isolation.

LAYER 1 • PRE-DISPATCH
🛡️

Plan-Time Validator

Rejects overlapping write scopes before a single token is spent. It is a conservative over-approximation:

✗ Collision: src/routes/ & src/routes/users.ts
✓ Disjoint: src/auth.ts & src/billing.ts
Over-reporting costs 1 re-plan; under-reporting costs a merge conflict.
LAYER 2 • IN FLIGHT (AIRTIGHT)
🌿

Per-Associate Git Worktrees

Each associate gets its own isolated git worktree on disk. Two workers physically cannot be in one file at the same moment.

Worker 1: .git/worktrees/associate-ui/
Worker 2: .git/worktrees/associate-db/
Files are copied back to main tree ONLY after mechanical checks pass!
LAYER 3 • POST-WORK
⚖️

Scope Gate & Mechanical Matrix

Audits what actually changed against what was declared. A worker that strayed is caught immediately.

Mechanical checks: Errors & warnings block
Judgement calls: Advisory, never block founder
Unverified checks are marked as unverified, not failed.
